# Якщо не вийшло

| Що бачите | Що робити |
|---|---|
| Claude каже, що інструментів qymcad немає | Повністю перезапустіть Claude Desktop (не лише вікно); у Claude Code — `claude mcp list`; за потреби — «Підключити до Claude» ще раз |
| macOS каже, що програма пошкоджена, або не дає її запустити | Зніміть карантин командою з `ПРОЧИТАЙ.txt` в архіві й повторіть |
| Після оновлення QymCAD Claude не бачить інструментів | Натисніть «Підключити до Claude» ще раз і перезапустіть Claude |
| Деталь вийшла не там / отвори повз | Нагадайте, що заготовки стоять центром у нулі; попросіть «покажи зверху» |
| Фіча червона | Спитайте «чому вона червона?» — у відповіді є причина; попросіть інше значення |
| Файл не знайдено | Дайте повний шлях (`~/Downloads/...`) — відносний рахується від папки, де запущено Claude Code |
