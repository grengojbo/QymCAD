# Фаска

Клавіша **C**.

![Фаска зрізає ребро площиною — на відміну від заокруглення, поверхня лишається плоскою.](img/part-chamfer.png)

## Як зробити

1. Виберіть ребра — клацання по ребру; клацання по грані бере всі її ребра. Те, що вибрано до команди,
   береться одразу.
2. Спосіб — у смузі зверху: **Симетрично** (один **Катет**), **Дві відстані** (два катети), **Катет + кут**. Для
   асиметричних способів **Опорна грань** каже, від якої грані відмірюється перший катет.
3. Значення вводяться в поля біля геометрії; попередній перегляд показує зріз до застосування. **Enter** застосовує,
   **Esc** скасовує.

## Чим відрізняється від заокруглення

Фаска зрізає кут площиною, заокруглення — дугою: фаска на ребрі полегшує вхід деталі й прибирає задирку,
заокруглення знижує концентрацію напружень. На отворі фаска — це зенківка; якщо отвір зроблено через
[Отвір](part/08-hole), задайте зенківку в ньому.

## Якщо не вийшло

- Катет відхилено до **Enter** — він більший, ніж дозволяє сусідня грань; причину написано біля
  поля.
- Вузол жовтий, деякі ребра лишилися гострими — ці ребра не вдалося взяти, решту зрізано. Відкрийте вузол
  подвійним клацанням і виберіть інші ребра або інший катет.
