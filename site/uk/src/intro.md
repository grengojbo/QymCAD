# Що це таке

Ви описуєте деталь словами, як описали б її знайомому конструктору: «пластина 60 на 40, товщина 4, чотири отвори під гвинт M3 по кутах, кути заокруглені». Claude будує з цього **справжню тверду модель** у QymCAD — з точними гранями, розмірами й історією побудови. Потім він сам її перевіряє: міряє, дивиться на картинку, шукає помилки. І зберігає файл для друку (3MF, STL) чи для іншої САПР (STEP).

Вміти моделювати не обов'язково. Корисно лише розуміти, що ви хочете отримати, і знати кілька розмірів.

Що для цього потрібно:

| Що | Навіщо |
|---|---|
| **Claude Desktop** або **Claude Code** | Розмова з Claude. Desktop — звичайна програма з вікном чату; Code — те саме в терміналі, для тих, хто з ним працює. |
| **QymCAD** | Сама програма. Разом із нею встановлюється сервер `qymcad-mcp`, через який Claude керує моделюванням «за лаштунками», без вікна. Вікно знадобиться, щоб підключитися до Claude, відкрити результат, покрутити його й щось поправити руками — або щоб Claude працював просто в ньому (див. [Claude у вікні QymCAD](live.md)). |
| **Слайсер** (за бажанням) | Bambu Studio, OrcaSlicer, PrusaSlicer — щоб надрукувати 3MF чи STL. |
