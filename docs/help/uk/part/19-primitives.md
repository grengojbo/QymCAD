# Примітиви

Тіло без ескізу, лише за розмірами: куб, циліндр, куля, конус, тор, призма. Кнопки — у групі
«Примітиви».

![Куб і циліндр — готові тіла, ескіз для них не потрібен.](img/part-primitives.png)

## Як зробити

1. Натисніть кнопку примітива: **Куб** (клавіша **B**), **Циліндр** (**Y**), **Куля**, **Конус**, **Тор**,
   **Призма**.
2. Введіть розміри в поля біля геометрії (які саме — нижче).
3. Куди поставити — клацніть вершину, датум-точку, площину або грань: примітив стане там своєю основою.
   Без клацання він стоїть у початку координат деталі.
4. **Enter** застосовує, **Esc** скасовує.

Поля розмірів:

- **Куб** — Довжина X, Ширина Y, Висота Z;
- **Циліндр** — Радіус і Висота;
- **Куля** — Радіус;
- **Конус** — Радіус низу, Радіус верху й Висота; верх 0 дає гострий конус, більше за нуль — зрізаний;
- **Тор** — R кільця й r труби;
- **Призма** — Радіус (описаний), Висота й Сторін (від 3 до 64).

Розміри приймають формулу й редагуються згодом подвійним клацанням по рядку стрічки, як для будь-якої операції.

## Що далі

Деталь — одне тіло: другий примітив не створює другого тіла, а зливається з першим. Щойно форма
перестає вкладатися в ці числа — фланець, лиска, паз — переходьте до ескізу: збирати складну деталь із примітивів
дорожче, ніж накреслити контур.

## Якщо не вийшло

- Поле не приймає значення — нуль, від’ємне або не число; причину написано біля поля.
- Тор не будується — труба не тонша за кільце: такий тор проходить крізь себе. Зробіть r труби
  меншим за R кільця.
