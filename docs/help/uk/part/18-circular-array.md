# Круговий масив

![Вісім копій по колу: відстань від осі задає сама деталь.](img/part-array-circular.png)

## Як зробити

1. Виберіть тіло й натисніть **Круговий масив** — або натисніть кнопку й клацніть тіло.
2. У смузі зверху: **Копій** — скільки по колу; **Вісь** — за замовчуванням **Z (світ)**. Клацніть її кнопку й
   виберіть датум-вісь, пряме ребро, циліндричну грань (береться її вісь) або по черзі дві точки. Кнопка **Z**
   повертає світову вісь.
3. **Повне коло (360°)** розставляє копії рівномірно по всьому колу. Зніміть позначку — біля геометрії з’явиться **Кут**
   сектора: скажімо, чотири отвори на чверті фланця.
4. **Enter** застосовує, **Esc** скасовує.

Вісь, узята з деталі, іде за нею: масив лишається співвісним за будь-якої правки.

## Якщо не вийшло

- Вісь не береться — клацнуте не є ні прямим ребром, ні циліндром, ні датум-віссю. Візьміть вісь за двома
  точками.
- Копії пішли не туди — вибрано не ту вісь: подивіться, що смуга каже біля **Вісь**, і виберіть знову.
