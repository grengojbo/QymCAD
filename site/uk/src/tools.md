# Усі інструменти коротко

| Група | Інструменти |
|---|---|
| Документ | `new_project`, `open_project`, `save_project`, `get_document`, `undo`, `redo` |
| Параметри | `set_parameter`, `delete_parameter`, `list_parameters` |
| Заготовки | `box`, `cylinder`, `sphere`, `cone`, `torus`, `prism` |
| Ескізи | `create_sketch`, `sketch_add`, `sketch_info` |
| Тіло з ескізу | `extrude`, `revolve` |
| Обробка | `fillet`, `chamfer`, `hole`, `shell`, `push_face` |
| Копії й переміщення | `linear_pattern`, `circular_pattern`, `mirror`, `move`, `boolean`, `split_body` |
| Деталі й історія | `add_part`, `set_active_part`, `edit_feature`, `suppress_feature`, `delete_feature` |
| Вікно | `get_selection` — що вибрано у вікні; `render` з видом `window` — як бачите ви |
| Перевірка | `render`, `inspect`, `measure`, `list_faces`, `list_edges`, `resolve` |
| Файли | `import_mesh`, `import_cad`, `export_mesh`, `export_cad` |
| Пакет | `apply_ops` — кілька дій одним кроком |

Також є **ресурси** (`qymcad://document`, `qymcad://feature/{key}`) і **промпти** (`design_for_fdm`, `edit_stl`, `edit_step`, `edit_what_i_selected`).
