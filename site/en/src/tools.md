# All the tools in short

| Group | Tools |
|---|---|
| Document | `new_project`, `open_project`, `save_project`, `get_document`, `undo`, `redo` |
| Parameters | `set_parameter`, `delete_parameter`, `list_parameters` |
| Starting shapes | `box`, `cylinder`, `sphere`, `cone`, `torus`, `prism` |
| Sketches | `create_sketch`, `sketch_add`, `sketch_info` |
| A body from a sketch | `extrude`, `revolve` |
| Finishing | `fillet`, `chamfer`, `hole`, `shell`, `push_face` |
| Copies and moves | `linear_pattern`, `circular_pattern`, `mirror`, `move`, `boolean`, `split_body` |
| Parts and history | `add_part`, `set_active_part`, `edit_feature`, `suppress_feature`, `delete_feature` |
| Window | `get_selection` — what is selected in the window; `render` with view `window` — as you see it |
| Checking | `render`, `inspect`, `measure`, `list_faces`, `list_edges`, `resolve` |
| Files | `import_mesh`, `import_cad`, `export_mesh`, `export_cad` |
| Batch | `apply_ops` — several actions as one step |

There are also **resources** (`qymcad://document`, `qymcad://feature/{key}`) and **prompts** (`design_for_fdm`, `edit_stl`, `edit_step`, `edit_what_i_selected`).
