# Обмеження ескізу

Кнопки обмежень стоять ліворуч, у групі «Обмеження». Обмеження — це правило між елементами
ескізу: лінія горизонтальна, дві лінії рівні, коло торкається лінії. Розмір задає число, обмеження —
положення; разом вони визначають ескіз.

## Як додати обмеження

Два способи, один результат:

- **Спершу вибір.** Виберіть стрілкою те, що пов'язуєте (Shift додає до вибору), натисніть кнопку
  обмеження. Обмеження додається одразу.
- **Спершу кнопка.** Натисніть кнопку, коли нічого не вибрано, — рядок стану попросить елементи. Клацніть їх на
  полотні; обмеження додається, щойно в нього є все потрібне. Esc скасовує.

Якщо вибране не те, що приймає обмеження (дві точки для паралельності, дві лінії для середини), програма
скаже, що їй потрібно, і почне вибір спочатку.

## Що є

| Обмеження | Куди вказати | Що з цього виходить |
|---|---|---|
| Горизонталь | лінія або дві точки | лінія (або відрізок між точками) стає горизонтальною |
| Вертикаль | лінія або дві точки | вона стає вертикальною |
| Паралельно | дві лінії | лінії стають паралельними |
| Перпендикулярно | дві лінії | вони сходяться під прямим кутом |
| Рівна довжина | дві лінії | довжини стають рівними; для кіл — радіуси |
| Колінеарно | дві лінії | вони лежать на одній прямій |
| Концентрично | два кола або дуги | центри збігаються |
| Дотичність | лінія й коло | лінія торкається кола |
| Середина | точка й лінія | точка переходить на середину лінії |
| Збіг | дві точки, або точка й лінія | точки сходяться; точка лягає на лінію |
| Зафіксувати | точки | точки лишаються на місці за будь-якої правки |
| Симетрія | дві точки й лінія як вісь | точки віддзеркалюють одна одну відносно осі |

## Де вони показуються

Кожне обмеження малюється позначкою біля своєї геометрії та рядком у списку обмежень праворуч. Клацання
по позначці вибирає обмеження, Delete видаляє його. Ступені свободи внизу вікна показують, скільки
ще лишилося визначити.

## Якщо обмеження не додається

- **Воно сперечається з іншими.** Програма підсвічує суперечність червоним: приберіть зайве обмеження чи розмір.
- **Воно зайве.** Якщо те саме вже задано іншими обмеженнями, нове нічого не змінює — ескіз
  уже визначено.
- **Вибрано не те.** Прочитайте рядок стану: він називає, що саме приймає це обмеження.
