# Дзеркало в ескізі

Клавіша **M**.

![Півконтуру та його відображення відносно допоміжної осьової лінії.](img/sketch-mirror.png)

![Штрихова лінія між колами — допоміжна: вона тримає задум, але в тіло не йде.](img/sketch-construction.png)

## Як зробити

1. Виберіть, що відобразити, і натисніть **Дзеркало**. Або навпаки: натисніть **Дзеркало**, потім клацніть, що
   відобразити.
2. Щоб додати ще: **Shift** + клацання по лінії чи дузі або **Shift** + рамка.
3. Звичайне клацання вказує, відносно чого відображати: лінію ескізу (зокрема допоміжну), вісь X чи Y ескізу або
   точку. Відносно точки копія лягає по той бік від неї, на тій самій відстані.
4. Відображення робиться одразу, один крок скасування. Інструмент лишається в руці для наступної геометрії; **Esc**
   відкладає його.

Для симетричної деталі накресліть одну половину, накресліть осьову лінію як **допоміжну** (клавіша **X**) і віддзеркальте відносно неї:
осьова лінія лишається поза профілем тіла.

## Що ви отримуєте

Відображення — це **копія**: воно не пов'язане з оригіналом. Змінили половину — віддзеркальте її знову, або додайте
обмеження **Симетрія** між парами точок самі.

## Якщо не вийшло

- Нічого не відобразилося — не вибрано, що відображати. Клацніть лінію чи дугу, потім вісь.
- Клацання відобразило замість додати — тримайте **Shift**, коли додаєте геометрію.
